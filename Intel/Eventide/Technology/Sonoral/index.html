SoRT Microarchitecture

Five blocks. One deadline.

Each SoRT cluster is a short, deep pipeline of fixed-function blocks built around a single scheduling truth: an impulse-response update is due every 2.67 ms, and it is never allowed to be late. No shader cores, no occupancy games — every block exists because a closed-form acoustic quantity wanted silicon.

Fixed Resolver Roster

Seven resolvers. Zero shaders.

Graphics needed programmable shading because surface appearance is open-ended. Acoustic propagation is not: every quantity below is closed-form or low-dimensional, which is precisely the argument for casting it as fixed-function silicon. Per core, per ray, per block — these run in lockstep with traversal.

Distance Attenuation

Spherical spreading (1/r) plus ISO 9613 per-band atmospheric absorption, held in ROM. Two table lookups and a multiply — there is nothing to program, so nothing programmable was built.

Doppler

The TE already computes high-precision path length per frame; Doppler is its time derivative mapped to a resample ratio. One subtraction, one divide — the resolver is nearly free because the traversal payload was designed for it.

Material Coefficient Fetch

6-bit material index into the local 8 KB LUT: 8 absorption bands × 16-bit, single-cycle. Sits inside the innermost intersection loop, which is why it is the one deliberately local memory in the design.

UTD Edge Diffraction

The Uniform Theory of Diffraction reduces an edge to a closed-form coefficient per band, given geometry the bake already flagged. Low-dimensional inputs, deterministic output — a textbook fixed-function candidate, and the feature software ray tracers habitually fake.

Woodworth ITD / Head-Shadow ILD

Interaural time from the Woodworth model, level from a frequency-dependent head-shadow fit, plus a creeping-wave LF shelf. Head radius is a runtime parameter, not a bake constant. Feeds the BDU's per-ear fork.

Source Directivity

Spherical-harmonic cardioid-family polar patterns evaluated per band. A handful of SH coefficients per source covers loudspeakers, voices and engines — low-dimensional by construction.

Ambisonic / HOA Encode

Direction to spherical-harmonic weights: a fixed matrix multiply. Emits scene-agnostic soundfield components for downstream mixers and the codec bridge without a render-to-channels detour.

Memory Hierarchy

One cache. One exception.

SoRT owns almost no memory. The acoustic BLAS lives in shared bLLC (Kache Kore) beside the graphics BVH it was decimated from; HRTF sets, transducer profiles and IR history ride the central memory controller and ZAM bandwidth. The design duplicates nothing — except one 8 KB table, on purpose.

Latency / capacity ladder — what audio data lives at each rung
The Material Coefficient LUT is the single deliberately local structure: it sits inside the intersection loop, where a 9 ns bLLC round-trip would cost ~22 potential ray-steps per fetch at TE rates. Latency merit earned its 8 KB of SRAM; nothing else made that case.

Methodology

All four paths consume the same .ablx acoustic BLAS and the same source set. CPU software is a SIMD-optimized geometric tracer on 4 P-cores; GPU compute runs the same kernel via compute queues; RTU-shared time-slices the Druid GPU's RTU4 ray units between frame rendering and audio batches; SoRT is a single Core 500 cluster. Power figures are the marginal draw attributable to the audio workload, measured at the package rails over a 10-minute traversal-heavy loop. Latency is motion event to transducer drive signal, including output-stage cost on the identical Hallraum path.

The scheduling-domain argument

Audio deadlines and render deadlines are different clocks. A frame is due every 8–16 ms and may slip a frame under load; an audio block is due every 2.67 ms and a miss is an audible glitch, not a dropped frame. Any shared-hardware scheme must arbitrate between these domains — and under combined load, one of them loses. SoRT never arbitrates: its scheduling domain is the audio block, alone, always. That is why its frame impact is exactly 0.0% and why its latency has no long tail.

Counterargument, kept on record

On dual-GPU systems — an Elementalist dGPU rendering while the Druid iGPU idles — the idle GPU's RTU4 units could absorb the acoustic workload at zero frame cost, and the 640 mW figure would drop meaningfully. We ran it; it works. It ships nowhere. Two reasons: deterministic cross-tier behavior — a feature that exists only when a second GPU is present is a feature titles cannot depend on, and the handhelds that need acoustic offload most are exactly the single-GPU machines it abandons; and clock-domain mismatch — the iGPU's power-management ramps are tuned for burst rendering, not a hard 2.67 ms heartbeat, and holding it awake at audio cadence erases most of the power win. The dedicated block is smaller, always present, and always the same.

Design Debts

What it can't do. Written down.

Every architecture carries debts. These are Sonoral's, stated plainly — with what we did about each.

01

Geometric acoustics fails below ~200 Hz

In small rooms, sub-200 Hz wavelengths reach room scale and standing-wave modes dominate — no ray count fixes a wrong physical model. The answer is architectural, not incremental: Tiefton, Klangkerne's FEM-baked modal-correction subsystem, owns everything below the 180 Hz crossover. SoRT does not pretend to trace where rays are not physics.

02

The acoustic BLAS is a bake-time cost

Decimation, material assignment and edge flagging run offline in the NewGen bake tool — roughly 4 s per reverb zone for the Tiefton FEM solve on a Core 500 development machine, plus the proxy build itself. Fully dynamic geometry (destruction beyond TLAS refit granularity) inherits stale acoustic proxies until the next bake. Runtime refit covers transforms and visibility; it does not re-decimate.

03

The HRTF individualization ceiling

With a generic 720-direction HRTF set, front/back confusion remains the realism ceiling — a property of human hearing, not of the silicon. The hardware renders its transfer function faithfully; the function worth rendering is per-human. Photogrammetry personalization (a delta layer over the base set, first-party tier) is the mitigation, not a cure.
